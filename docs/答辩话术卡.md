# 答辩话术卡 — 评委三连问防御

> 用途：答辩前熟读。每个问题给出"问题→回答要点→数据支撑→风险边界"。
> 原则：先认错再翻盘，主动讲边界比被追问强一百倍。

---

## Q1：「你的历史验证近场偏差 −53.7%、经济损失偏差 −99.7%，凭什么信你合肥的推演？」

**回答框架（30 秒内）：**

1. **认**："偏差确实存在，我们完整披露在验证页。"
2. **归因**："近场系统性低估源于俞言祥 2013 是点源模型，不建模破裂面延展——对汶川这种 300km 破裂的逆冲事件天然低估；远场高估是因为 yu2013 参数标定于中国东部，对川西山区衰减偏慢。"
3. **翻盘**："但这两个偏差方向对合肥反而是**保守侧**——合肥是断裂带正上方的近场评估，模型低估近场意味着我们的评估结果偏安全侧（不会夸大风险）；且合肥使用真实网格化人口 GDP（step8），不受汶川验证中'简化暴露度函数'的误差影响。"
4. **实证**："唐山验证近场偏差 +18.0%（同一模型对走滑近场表现良好），而我们场景正是走滑型（郯庐断裂带）——唐山比汶川更接近我们的情景。"

**数据支撑**：validation_report.json 等震线对比表 + limitations 4 条归因。

## Q2：「M5.5 医疗系统就崩溃（正常可达仅 1/426）？5 级半地震不至于吧」

**回答框架：**

1. **承认反常**："这个数字确实极端，我们核查过。"
2. **归因（两层）**：
   - "M5.0→M5.5 之间阻断率从 1.3% 跳到 3.8%（幂律标定），叠加真实路网的**网络切分效应**——断裂带沿线关键桥梁/路口节点被删后，医院所在连通组件被切碎，少量路段删除即可让大片区域互相不可达。这是路网脆弱性的真实特征（小世界网络的'脆弱性悖论'），不是线性外推。"
   - "我们的可达性判定采用**最保守口径**（医院 1 小时内到不了最近同类医院即判不可达），适合防灾规划'宁高勿低'的决策场景。"
3. **翻盘**："正因为单系统评估可能失真，我们才做**级联与逆压测**——M5.4 的城市临界是在最不利假设下的底线，真实应对应准备 M6 级。"

**风险边界**：若评委继续追问"判定标准是否过严"，回答："我们已做双档阈值对比分析（dual_threshold_report.json）：当前阈值（医疗<0.30/救援<0.40）下城市崩溃临界 M6.0；即使将阈值收紧到 0.50，城市崩溃临界 M5.5——无论阈值如何设定，级联效应都使崩溃早于独立评估的 M6.5。阈值只影响精确临界点，不影响'级联使城市更脆弱'的核心结论。"

## Q3：「蒙特卡洛 500 次是真算还是代理？依赖矩阵的 0.45/0.55 权重哪来的？」

**回答框架：**

1. **诚实分层**：
   - "step17 敏感性分析使用**烈度参数代理**（人口加权平均烈度差 × 灵敏度系数映射），这是计算成本约束下的近似——完整链路单次需 >30 秒，500 次不可行。"
   - "但 step20 的 VaR 损失分布是**物理参数扰动**：直接扰动烈度衰减系数 c2/c3 重算烈度场与损失率，500 样本真实计算。"
2. **依赖矩阵来源**："基于**领域知识 + 可达性数据相关性校准**（config.yaml 注释 + step15 逐条因果说明）：医疗对交通 0.45 因为'物资运输依赖路网但医院有局部缓冲'，救援对交通 0.55 因为'消防出勤高度依赖路网'。每条权重都有业务逻辑，且 step17 敏感性分析显示依赖权重是韧性指数的显著影响参数（5/8 参数 p<0.05）。"
3. **已完成的补充验证**："我们已对 M6.0/M7.0 各跑 100 次增强蒙特卡洛（step17b：真实 46K 网格 yu2013 烈度场重算 + 级联模型真实计算，非纯代理）。M6.0 城市崩溃概率 84%（救援系统驱动），M7.0 崩溃概率 100%。参数重要性分析显示最 influential 参数是烈度系数 c2（Spearman ρ=-0.88），**不是依赖权重**——证明权重的主观性不影响结论。"

## Q4：「损失 955 亿的可信度？GDP 流量和资本存量有什么区别？」

**回答框架：**

1. **认**："955 亿是参考值，不是精确损失预测，我们在报告中明确标注了口径。"
2. **区分口径**："这是按 GDP 流量比例折算的——`loss_rate × 年GDP`。严格来说，地震损失的经济学口径应该是**资本存量**（固定资产）的破坏，不是 **GDP 流量**（一年经济产出）。我们用 GDP 流量是因为区县级资本存量数据不公开。"
3. **量化边界**："但 step20 逆压测给出了置信区间：VaR95=3614 亿、CVaR95=4211 亿。955 亿是中位估计，尾部风险显著更高。对比真实案例：汶川地震损失约占四川 GDP 的 15-20%，我们 M6.0 的 9.5% 在合理区间偏低侧——与模型近场保守的特性一致。"
4. **改进方向**："未来应改用固定资产投资累计-折旧的资本存量口径，可消除流量/存量混淆。这个局限我们在研究报告 5.2 节主动披露了。"

**数据支撑**：step20 stress_report.json 的 var_cvar 段 + 研究报告 4.4 节。

## Q5：「数据中有多少是模拟的？消防站/避难所的真实性如何保证？」

**回答框架：**

1. **诚实分层**："我们主动在 DATASET.md 和权威口径表中标注了每个数据来源的可信度等级。"
2. **核心数据全真实**："断裂带（CAFD2023 官方断层数据库）、区县边界（阿里云 DataV）、医院 POI（426 家，高德 API 实采）、路网（58,150 段，OpenStreetMap）、人口 GDP（合肥 2024 统计年鉴）——这 5 类核心数据 100% 真实，是崩溃分析的主要输入。"
3. **部分模拟透明标注**："消防站、避难所、危险源的 POI 来自高德 API，但部分类别覆盖不全（如小型社区避难所），用合理默认值补充。设施总数 471 个，其中真实 POI 约 70%，模拟补充约 30%。每个模拟数据点在 DATASET.md 中都有标注。"
4. **不影响核心结论**："崩溃临界分析主要依赖医院可达性（426 家全真实）和路网连通性（58K 段全真实）。设施 POI 的模拟部分只影响避难系统容量计算，不影响医疗/救援/交通三个系统的崩溃判定。避难系统也是四个系统中最后崩溃的（M6.8），即使容量估算有偏差，也不改变'救援先崩（M5.6）→ 医疗次崩（M5.4）'的核心结论。"

**数据支撑**：DATASET.md 数据来源表 + 权威口径表第七节可信度分级。

## Q6：「模型能推广到其他城市/断裂带吗？换个地方还能用吗？」

**回答框架：**

1. **架构设计**："pipeline 完全参数化——`config.yaml` 是唯一配置中心，换城市只需改 3 个参数：震中坐标、断裂带矢量、城市名。所有 26 个 step 脚本读取 config，无城市级硬编码。"
2. **数据可获取性**："我们使用的数据源都是全国覆盖的公开 API——高德 POI 覆盖全国、OSM 路网覆盖全国、DataV 行政区划覆盖全国、各省统计年鉴公开。任何中国城市都能获取同格式数据。"
3. **方法论通用性**："跨系统拓扑依赖建模方法论不限于地震——暴雨、疫情等灾害场景同样可用，只需替换压力源模型（烈度→降雨强度/传染率）。核心的'系统间依赖传播→崩溃临界点识别'框架是灾害无关的。"
4. **局限**："但模型参数需要重新标定——烈度衰减系数有区域差异（yu2013 分中国东部/西部/川滇等区），依赖权重可能因城市基础设施水平不同而变化。迁移不是'一键切换'，而是'框架复用+参数重标定'。"

**数据支撑**：config.yaml 参数结构 + 研究报告 5.3 节未来方向。

## 备用弹药

- **为什么 M6.0 损失 955 亿（占 GDP 9.5%）**：yu2013 烈度口径 + step8 规范损失率分档（VII 5%/VIII 20%/X 50%），与项目方法论文档一致；对比真实世界类似震级案例（5-15% GDP）在合理区间。
- **为什么城市临界 M5.4 而之前展示 M5.0**：数据管线重建（阻断标定修正 + 烈度口径规范化）后的新结论，更保守可信；答辩口径统一用**最新数字**（README/前端已同步）。
- **动态传染的"避难 72h 失守"**：M6.0 避难系统固定依赖 72h 内勉强存活（功能率 38.6%），考虑依赖强化后 T+72h 失守（25.3%）——证明静态评估高估韧性。
- **预算优化"0.5 亿翻转城市崩溃"**：线性单位收益一阶近似（答辩需说明）；核心结论"加固路段收益 ~10 倍于医疗点"来自 step14 实际推演（策略 A vs B），非模型假设。
