## 2026-07-10 Step 4 (模块1A): 网格化暴露度与地震损失初估

**目标**：500m网格化合肥全域，计算地震烈度衰减 + 医院功能损失初估

**模型**：
- 震级 M=6.0，震中取断裂带中点
- 烈度衰减：I = 0.5 + 1.5×M - 1.0×ln(R+5)
- 损失率分档：I<5→0%, 5≤I<7→5%, 7≤I<8→20%, I≥8→50%
- 投影坐标系 EPSG:4527 做距离计算

**完成事项**：

### v0.4: 三维参数交互骨架

**目标**：补全发震时段、老旧建筑占比、次生灾害阻断半径三个动态参数。

**侧边栏新增控件**：
- `st.radio` 发震时段（白天/夜晚），默认白天
- `st.slider` 老旧建筑占比（0-50%，步长 5%），默认 20%
- `st.slider` 次生灾害阻断半径（5-20km，步长 1km），默认 10km

**公式重构**：
- β 系数：白天 = 1.0, 夜晚 = 1.5
- 脆弱性指数 Vi = old_building_pct / 200（0%→0, 50%→0.25）
- 抗震设防折减 α = 0.8（常量）
- 损失修正倍率 = (Vi / Vi_default) × (β / β_default)

**阻断半径联动**：
- 新增 `filter_roads_by_radius()` 函数：路段到断裂带距离 > 阻断半径 → `block_level` 改为"正常"
- 过滤后重算可达性 `compute_accessibility()`，结果写入 `scenario["access"]`
- 将所有下游代码中的 `scenario["roads"]` 替换为 `filtered_roads`

**踩坑**：
- `filtered_roads` 在定义前被 `roads_4326 = to_4326(filtered_roads)` 引用 → NameError。修复：将引用移到定义之后
- `hosp_gdf_proj`（430行）与 `scenario["access"]`（426行）行数不一致 → ValueError。根因：4家医院名称不匹配。修复：`compute_accessibility` 和 `recompute_accessibility` 都改为按 `access_df` 名称遍历，通过 `geom_map = dict(zip(name, geometry))` 反查几何

**版本号**：v0.3 → v0.4

### v0.7: 高风险-低韧性排行榜 + 救援延误时间矩阵

**目标**：将单一损失排行升级为韧性维度综合排名，新增区县到急救枢纽的延误矩阵。

**高风险-低韧性排行榜**：
- 风险指数公式：`损失率×0.4 + 不可达率×0.4 + 老旧建筑占比×0.2`
- 按区县汇总不可达率（从 `accessibility_M*.csv` 按 `district` 列 groupby）
- `risk_df` 合并 loss + district stats，fillna 防 NaN
- Pandas Styler 红色渐变（风险指数越高越红）
- 风险等级标签：🔴 高风险(≥0.25) / 🟡 中风险(≥0.15) / 🟢 低风险
- 损失率和不可达率列也加成色阶
- 底部标注"老旧建筑占比 XX% 已纳入风险指数计算"

**救援延误时间矩阵**：
- 计算逻辑：区县质心 → 可达医院（正常可达 + 可达但受限）的直线距离
- 行车时间估算：距离 / 35km/h × 路网阻断系数（每条阻断路段边际影响 0.02×penalty）
- 每个区县取最近 3 个急救枢纽
- 透视表展示：行=区县, 列=优先级(1st/2nd/3rd), 值=预计小时
- 🔴 红色高亮 >2h 的重度延误格子
- 底部 Expander 折叠（默认关闭），展开后显示完整矩阵 + 详细清单
- 零可达医院降级：提示"无可达急救枢纽，请降低阻断半径或选择较低震级"

**踩坑**：
- `st.markdown("</div>")` 出现两次 → Edit 需更多上下文精确匹配

## 2026-07-12 NetworkX 最短路径分析：buffer 画圈 → 真实路网连通性

**目标**：将"医院不可达"判定从 1km buffer 画圈升级为基于 42K 条 OSM 路段的 NetworkX 最短路径分析。这是作品推理链条最关键的一环——"路断了导致医院不可达"必须有图论算法支撑。

**技术方案**：
- 下载 OSMnx 路网图（16,238 节点 / 42,456 边），投影到 EPSG:4527
- 边属性：`travel_time`（行驶时间）、`dist_to_fault_m`（到断裂带距离）
- 震害模型：按距离+震级分级删除边/降低速度

- 医院分类：对比震前/震后服务范围（1 小时内可达节点数）

  - 可达但受限：30%-70%
