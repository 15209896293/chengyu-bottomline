## 执行规则

1. **不要删除或覆盖原始数据文件**，特别是 `数据文件/hefei_hospital.csv`（426家真实医院POI）和 `数据文件/hefei_road_graph.graphml`（58K路段路网图）
2. **新脚本用新文件名**（如 step8_loss_recalculation.py），不要直接修改现有脚本，便于回退
3. **每个 Python 脚本开头必须设置 GDAL/PROJ 路径**：
   ```python
   import os
   from pathlib import Path
   LIB = Path("F:/anaconda/envs/zhenmai/Library/share")
   os.environ.setdefault("GDAL_DATA", str(LIB / "gdal"))
   os.environ.setdefault("PROJ_LIB", str(LIB / "proj"))
   ```
4. **坐标系统一致**：地理坐标用 EPSG:4490，投影计算用 EPSG:4527
5. **随机种子固定**：所有涉及随机的代码用 `SEED = 42`，保证可复现
6. **输出编码**：CSV 文件用 `utf-8-sig` 编码，GeoJSON 用 `utf-8`
7. **每个脚本末尾必须有验证代码**，输出检查结果到控制台，验证不通过则打印失败原因
8. **如果某步失败**：记录错误信息，跳过该步继续执行后续步骤，最后统一报告所有失败项
9. **阶段间隔离**：每个阶段独立可运行，不依赖前序阶段的内存状态，只依赖文件输出
10. **Python 环境是 conda 环境 `zhenmai`**，运行命令格式：`conda run -n zhenmai python 脚本路径`
